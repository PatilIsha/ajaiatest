## Status

**Working end to end**
- Create, rename, edit, autosave, reopen, and delete documents, with rich text (bold, italic, underline, strikethrough, H1–H3, bulleted/numbered lists, quotes)
- File upload: .txt/.md/.docx → new document, or inserted at the cursor in an existing one
- Sharing by email with Can edit / Can view roles; change role or revoke; "My documents" vs "Shared with me"; read-only editor for viewers
- SQLite persistence; server-side HTML sanitization
- Conflict detection: a stale save is rejected and the user is offered the latest version, instead of overwriting someone else's work

**Partial / known limitations**
- Auth is mocked (seeded users only).
- The free-tier host has an ephemeral disk, so documents created there can reset when the instance restarts. Seed data always comes back.
- No real-time co-editing. Concurrent edits are detected, not merged.
- Imports drop images and flatten tables.

**Next 2–4 hours:** durable DB, version history with restore, a live "someone else is editing" indicator, a Playwright share-flow test, and Markdown/PDF export. Details are in `ARCHITECTURE.md`.
